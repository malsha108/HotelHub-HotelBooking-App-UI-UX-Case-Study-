# 🏨 HotelHub – Hotel Booking App (UI/UX Case Study)

## 🎯 Overview
A mobile app concept to help users discover and book hotels easily in Sri Lanka.

## 🧩 Key Features
* Home screen with Hotel Search & Filters
* Search Results screen with hotel details, price, location, and ratings
* Hotel Details view with booking options

## 🛠️ Tools Used
* Figma
* Auto Layout
* Component System
* Interactive Prototype

## 📱 Design
* iPhone 14 & 15 Pro (393px)
